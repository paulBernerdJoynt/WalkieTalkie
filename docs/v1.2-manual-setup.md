# v1.2 Manual Setup — Agentforce Prompt Builder

These steps must be completed in the `agentforce poc` Salesforce org **before** the Agentforce path in the LWC will work. The OpenAI path works immediately after code deploy; only the Agentforce path needs this setup.

---

## Step 1 — Verify Prompt Builder is Enabled

1. Setup → Einstein → Generative AI
2. Confirm **Einstein Generative AI** is toggled **on**
3. Setup → Prompt Builder — if this menu item exists, you're licensed ✓
   - If it doesn't appear, you need the Einstein generative features add-on for your org

---

## Step 2 — Create the Prompt Template

**Navigate to:** Setup → Prompt Builder → New

| Setting | Value |
|---------|-------|
| Template Name | CCC Extractor |
| Template Type | **Flex** |
| API Name | `CCC_Extractor` ← exact, case-sensitive |

**Add an Input Variable:**
- Click **Add Input**
- Name: `transcript`
- Type: Text
- Description: Raw Whisper transcription of technician narrative

**Paste this prompt body:**

```
You are a structured data extractor for a fleet vehicle maintenance system.

A field service technician has described work they performed on a vehicle.
Extract exactly three things from their description:

1. COMPLAINT — What was observed (the symptom or presenting issue)
2. CAUSE — The identified root cause
3. CORRECTION — The action taken to resolve the issue

Rules:
- Remove filler words, hesitations, and repetition
- Write each field in clean, professional technical language
- If a field cannot be determined, return null for that field
- Do not invent details not present in the technician's description
- Respond in this exact format and nothing else:

COMPLAINT: [value or null]
CAUSE: [value or null]
CORRECTION: [value or null]

Technician input:
{!transcript}
```

**Test in Preview before saving:**
- Enter a sample transcript in the `transcript` variable field
- Example: *"uh yeah so the truck came in with a vibration in the front, we found the front left wheel bearing was shot, we swapped it out and test drove it and it's good now"*
- Confirm the output strictly follows COMPLAINT / CAUSE / CORRECTION format with no preamble

**Save the template.**

---

## Step 3 — Create the Agent Action

**Navigate to:** Setup → Agentforce → Agent Actions → New

| Setting | Value |
|---------|-------|
| Action Type | **Prompt Template** |
| Prompt Template | CCC Extractor (the one you just created) |
| Action Label | Extract CCC From Transcript |
| API Name | `Extract_CCC_From_Transcript` |

Save.

---

## Step 4 — (Optional) Create a Lightweight Agent

> This wires the action into an agent for future multi-action flows. Not required for v1.2 Apex invocation but sets up the foundation for v1.3.

**Navigate to:** Setup → Agentforce → Agents → New Agent

| Setting | Value |
|---------|-------|
| Agent Type | Service Agent |
| Name | CCC Extractor Agent |

**Add the action:**
1. Open the agent → Topics → New Topic
2. Topic name: CCC Extraction
3. Add the `Extract_CCC_From_Transcript` action to the topic
4. Instructions: *"When a technician submits a maintenance narrative, call Extract CCC From Transcript and return the structured result."*

Save and **Activate** the agent.

---

## Step 5 — Verify API Name

After saving the Prompt Template, confirm the API name is exactly `CCC_Extractor`:
- Setup → Prompt Builder → click the template → check the **API Name** field
- If it auto-generated differently (e.g. `CCC_Extractor_1`), update the Apex constant in `CCCController.cls`:
  ```apex
  private static final String AGENTFORCE_TEMPLATE_API = 'CCC_Extractor'; // ← update if different
  ```

---

## Step 6 — Add New Fields to the Work Order Page Layout

The v1.2 deploy adds 7 new fields. Add them to the Work Order record page:

**Navigate to:** Object Manager → Work Order → Page Layouts → Work Order Layout

Add these fields to the layout (suggested: in a new section called "CCC Comparison"):

| Field | Column |
|-------|--------|
| CCC — Raw Transcript | Full width |
| OpenAI — Complaint | Left |
| Agentforce — Complaint | Right |
| OpenAI — Cause | Left |
| Agentforce — Cause | Right |
| OpenAI — Correction | Left |
| Agentforce — Correction | Right |

Save and assign to profiles.
